Family Player 개인정보 처리 안내

적용일: 2026년 11월 3일. Family Player는 개인과 가족을 위한 개인 서버 기반 웹 플레이어입니다.

계정 연결과 이용 목적

Google의 OAuth 인증을 사용하며 Google 비밀번호를 수집하지 않습니다. 계정 연결 시 YouTube 채널 식별자, 채널 이름, 프로필 이미지 주소와 접근·갱신 토큰을 개인 서버에 저장합니다. 토큰과 YouTube 정보는 연결한 사용자의 구독·재생목록을 조회하고 사용자가 요청한 구독 또는 재생목록 변경을 처리하는 데 사용합니다.

저장 위치와 보관

계정 연결 정보와 인증 토큰은 관리자의 개인 서버에 보관하며, 운영체제 파일 접근 권한으로 접근을 제한합니다. 시청 기록과 재생 위치는 이용 중인 브라우저의 로컬 저장소에 보관합니다. 요청한 다운로드 파일은 개인 서버에 임시 저장되며 전송 완료 또는 만료 시 정리됩니다.

외부 서비스와 공유

기능 제공을 위해 Google·YouTube에 API 및 콘텐츠 요청을 보냅니다. 협찬 구간 건너뛰기 기능을 이용하면 SponsorBlock에 영상 식별자로 구간 정보를 요청합니다. 해당 서비스에는 각 서비스의 개인정보 정책이 적용됩니다. Google 계정 데이터를 판매하거나 광고 목적으로 사용하지 않습니다.

각자 로그인한 계정의 연결 정보는 해당 로그인 세션에 연결됩니다. 관리자가 별도로 기기 연결을 승인하는 기능은 승인한 기기에서 관리자의 연결 계정을 함께 사용하는 기능입니다.

연결 해제와 삭제 요청

플레이어 설정에서 계정 연결을 해제할 수 있습니다. 연결 해제는 현재 브라우저의 연결을 해제하며, 서버에 보관된 계정 정보 전체를 자동 삭제하는 기능은 아닙니다. Google 계정의 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다.

서버에 남은 계정 정보·인증 토큰의 삭제는 관리자에게 요청할 수 있습니다. 브라우저의 시청 기록과 재생 위치는 브라우저 설정에서 이 사이트의 저장 데이터를 삭제하여 지울 수 있습니다.
